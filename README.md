# RothRaidManager

Simple raid utility panel derived from the Galaxy 2016 layout and updated with Midnight-safe fixes. It provides a movable, scalable panel with raid-marker utility controls and SavedVariables-backed options.

## Compatibility

- Interface: `120000` (alternate interface `120001`)
- Version: `0.3.0`
- Author: Galaxy (Roth UI) / modularized
- SavedVariables: `RothRaidManagerDB`

## Installation

Copy `RothRaidManager` into `World of Warcraft/_retail_/Interface/AddOns/`, enable it and reload the UI. Configure the panel through its AddOns settings entry.

## Development status

This is a compact legacy-derived addon with no prior development tracker. The repository now records panel creation, drag/scale persistence, raid-marker controls, combat behavior, and non-raid login validation in [todo.md](todo.md).
